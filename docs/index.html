RunCat Neo Twocats

菜单栏里的双猫版 —— RunCat Neo 的个人需求修改版

🐾 本项目是 RunCat Neo 的非官方修改版，原版在这里

RunCat Neo 由 Kyome22（Takuto Nakamura）开发，是一只跟随 CPU 负载在菜单栏奔跑的猫。全部核心设计、代码与创意均属于原作者，本仓库仅按个人需求做了少量修改。

这个版本改了什么What this fork changes

🐈‍⬛🐈 双跑者同屏（twocats）

菜单栏可同时显示两只跑者：主跑者 + 第二跑者，各自独立播放关键帧动画、独立按素材类型着色（剪影跟随菜单栏深浅模式，彩色保留原色）。第二跑者可在菜单栏菜单里随时选择或取消（None）。

↔️ 跑者间距可配置

两只跑者之间的间隔不再写死，可在 设置 → 跑者 → 外观 里用滑块调整（0–20px，默认 3px），拖动即时生效并持久化。

🔀 可与原版共存

使用独立 bundle id（com.changediff.twocats.RunCatNeo），与原版 RunCat Neo（或 App Store 版）互不冲突，可同时运行、偏好设置彼此隔离。

✅ 其余与原版保持一致

CPU 负载动画与速度联动、系统指标条、自定义指标、自定义跑者（编辑器 / 素材导入）等功能全部继承自原版。内置本地化（10 种语言）在新增文案处同步补齐。

自己构建Build

  • 要求：macOS 26.3+，Xcode 26.2+，Swift 6.2
  • 无签名证书时使用 ad-hoc 签名即可本地运行（无需描述文件）
xcodebuild -project RunCatNeo.xcodeproj -scheme RunCatNeo \
  -configuration Release -derivedDataPath build/DerivedData \
  -skipPackagePluginValidation -skipMacroValidation \
  CODE_SIGN_STYLE=Manual CODE_SIGN_IDENTITY=- DEVELOPMENT_TEAM= build

构建产物在 build/DerivedData/Build/Products/Release/RunCatNeo2cats.app，直接拷入 「应用程序」文件夹即可。更多开发约定见仓库中的 AGENTS.md 与 ARCHITECTURE.md。
